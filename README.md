# Superstore Executive Sales & Profit Dashboard

## Project Overview
This project was developed as part of DATHEON Internship Task 2. It transforms raw Superstore sales data into an interactive Power BI dashboard to analyze sales performance, profitability, regional trends and product performance.

## Tools and Technologies
- Microsoft Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query
- Star Schema Data Modeling

## Dashboard Features
- Interactive KPI scorecards
- Monthly sales trend analysis
- Regional sales performance
- Category and sub-category treemaps
- Product profitability matrix
- Dynamic date and region slicers
- Year-over-year sales growth analysis
- Conditional formatting for negative profits

## Data Model
The project uses a Star Schema with:
- Fact Table: superstore_sales
- Customer Dimension: DimCustomer
- Product Dimension: DimProduct
- Date Dimension: DateTable

## Key Performance Indicators

| KPI | Value |
|---|---:|
| Total Sales | 2.30M |
| Total Profit | 286.40K |
| Total Orders | 5,009 |
| Profit Margin | 12.47% |
| Latest Year YoY Sales Growth | 20.36% |

## Key Business Insights
- Technology generates the highest total sales and profit among the three categories.
- The West region leads in sales.
- Copiers generate the highest profit among sub-categories.
- Tables, Bookcases and Supplies generate negative profits.
- Sales increased by 20.36% in 2018 compared with 2017.
